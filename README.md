# Calistify

> Train smarter. Build stronger.

Calistify is a polished, responsive landing page for a calisthenics workout-tracking app. It presents the product's core experience—logging workouts, measuring strength progress, chasing personal records, and following skill progressions—in a high-contrast, mobile-first visual style.

This repository contains the marketing website only; it does not contain the Calistify mobile application or a backend.

## Highlights

- Responsive single-page product site with a mobile navigation menu
- Calisthenics-focused product sections for workout tracking, analytics, personal records, skills, exercise library, routines, and rest timers
- Interactive UI details: scroll-reveal animations, animated statistics, an FAQ accordion, SVG progress chart, and rest timer controls
- CSS-built phone mock-ups—no external product screenshots required
- Dedicated [Privacy Policy](privacy.html) and [Terms of Service](terms.html) pages
- No build step or package dependencies
